# 꾸메땅 영문법 게임

중학교 영문법 웹 게임 모음입니다. 주소 하나로 17개 게임을 풀 수 있습니다.

- 사이트 : https://kumettang-english.netlify.app
- 학생 결과는 구글 스프레드시트로 모입니다.

| 폴더 | 게임 |

| pumsa8 | 8품사 GAME |

| usedto | USED TO GAME |
