# 꾸메땅 영문법 게임

중학교 영문법 웹 게임 모음입니다. 주소 하나로 모든 게임을 풀 수 있습니다.

- 사이트 : https://hak5466.github.io (GitHub Pages)
- 학생 결과는 구글 스프레드시트로 모입니다.
- 모든 문법 게임은 4단계 80문제, 같은 방법으로 진행됩니다. 만드는 방법은 MANUAL.md에 있습니다.
